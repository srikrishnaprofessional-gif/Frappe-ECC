# /frappe:saas

Convert a Frappe application into a multi-tenant B2B SaaS with Stripe subscription billing and usage metering.

## Usage
```
/frappe:saas init [pricing_model]
```

## Examples
```
/frappe:saas init tiered-seats
```

## Description
Invokes `frappe-saas-multitenancy-orchestrator` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
