# /frappe:wireframe

**Purpose**: Generate visual wireframes (ASCII grid layouts, Markdown views, or SVG representations) for Frappe Desk forms, lists, dashboards, and mobile cards.

## Usage
`/frappe:wireframe "<DocType or Feature Name>" [--view form|list|workspace|mobile]`

## Execution Workflow
1. Invoke the **frappe-wireframe-builder** agent.
2. Activate the `frappe-wireframing-prototyping` skill.
3. Generate detailed visual wireframe layouts showing sections, column breaks, fields, indicators, action buttons, and child tables.
