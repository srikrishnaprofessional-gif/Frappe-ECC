# /frappe:training

Generate professional video narration scripts, interactive training quizzes, and operator certification rubrics.

## Usage
```
/frappe:training [project_name]
```

## Examples
```
/frappe:training equipment_loan
```

## Description
Invokes `frappe-training-video-scriptwriter` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
