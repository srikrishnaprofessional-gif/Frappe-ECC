# /frappe:workflow

Build visual BPMN state machines, approval hierarchies, and transition actions for any DocType without code.

## Usage
```
/frappe:workflow [doctype_name]
```

## Examples
```
/frappe:workflow 'Equipment Loan'
```

## Description
Invokes `frappe-bpmn-visual-workflow-builder` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
