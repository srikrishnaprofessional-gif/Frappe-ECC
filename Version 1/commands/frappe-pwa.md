# /frappe:pwa

Package any Frappe app as an installable mobile Progressive Web App (PWA) with camera barcode scanner.

## Usage
```
/frappe:pwa [app_name]
```

## Examples
```
/frappe:pwa equipment_loan
```

## Description
Invokes `frappe-mobile-app-pwa-generator` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
