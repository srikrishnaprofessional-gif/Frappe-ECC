Working SOP: Equipment Loan & Return

Download PDF SOP

SOP ID: SOP-EQP-001 | Role: Storekeeper, Borrower, IT Admin

Procedure 1: Creating a New Equipment Loan Application

  1. Navigate to Desk > Equipment Loan > New.
  2. Select the Borrower (Employee email). System verifies borrower has zero overdue loans.
  3. Input Scheduled Return Date (Maximum duration: 30 days).
  4. In the Allocated Hardware child table, add serial items.
  5. Click Submit. System automatically marks asset records as Loaned Out.

Procedure 2: Processing Equipment Return

Click the Process Return button in the upper action bar. In the modal checklist, inspect the hardware condition (Good, Scratched, Damaged). Upon submission, assets are released back to Available.

import frappe
from frappe import _
from frappe.model.document import Document
from frappe.utils import getdate

class EquipmentLoan(Document):
    def validate(self):
        # 1. Date Validation
        if getdate(self.return_date) <= getdate(self.loan_date):
            frappe.throw(_("Scheduled Return Date must be after Loan Date."))
            
        # 2. Borrower Overdue Check
        overdue = frappe.get_all("Equipment Loan", filters={
            "borrower": self.borrower, "status": "Overdue", "docstatus": 1
        })
        if overdue:
            frappe.throw(_("Borrower has active overdue loans. Please return overdue items first."))

    def on_submit(self):
        self.status = "Active"
        for item in self.items:
            frappe.db.set_value("Loanable Asset", item.asset, "status", "Loaned Out")

    def on_cancel(self):
        self.status = "Cancelled"
        for item in self.items:
            frappe.db.set_value("Loanable Asset", item.asset, "status", "Available")
