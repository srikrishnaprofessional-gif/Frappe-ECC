# /frappe:print-format

Autonomous Jinja2 print format and PDF document generator for Frappe Framework.

## Usage
```
/frappe:print-format "<DocType Name>" [--type invoice|receipt|voucher|label]
```

## Description
Invokes `frappe-print-format-designer` to create print-ready HTML/CSS Jinja templates with corporate letterhead, tax calculations, QR codes, and page-break rules.
