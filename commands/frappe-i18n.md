# /frappe:i18n

Localize application DocTypes, messages, and print formats into 100+ languages including RTL.

## Usage
```
/frappe:i18n [target_languages]
```

## Examples
```
/frappe:i18n 'es,fr,de,ar,hi'
```

## Description
Invokes `frappe-multilingual-localization-agent` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
