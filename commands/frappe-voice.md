# /frappe:voice

Configure voice-to-action handlers and spoken audio executive briefings for Frappe Desk.

## Usage
```
/frappe:voice [action_or_query]
```

## Examples
```
/frappe:voice setup-desk-mic
```

## Description
Invokes `frappe-voice-command-copilot` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
