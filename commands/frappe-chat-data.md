# /frappe:chat-data

Chat with your ERP data in plain English to receive instant tables, charts, and narrative insights.

## Usage
```
/frappe:chat-data [plain_english_question]
```

## Examples
```
/frappe:chat-data "Show me the top 5 most borrowed items this month"
```

## Description
Invokes `frappe-natural-language-query-agent` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
