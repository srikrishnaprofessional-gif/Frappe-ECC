# /frappe:prompt-to-app

Synthesize a complete, production-ready Frappe/ERPNext application directly from a natural language prompt.

## Usage
```
/frappe:prompt-to-app [natural language prompt]
```

## Examples
```
/frappe:prompt-to-app "Build a fleet management system with vehicle dispatch and fuel tracking"
```

## Description
Invokes `frappe-prompt-to-app-builder` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
