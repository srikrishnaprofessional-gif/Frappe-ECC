# /frappe:portal

Generate customer and supplier self-service web portals, catalogs, and extranet dashboards.

## Usage
```
/frappe:portal [portal_type]
```

## Examples
```
/frappe:portal customer-equipment-booking
```

## Description
Invokes `frappe-portal-ecommerce-builder` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
