# /frappe:tour

Author and inject in-app interactive guided walkthrough tours for new users and operators.

## Usage
```
/frappe:tour [doctype_name]
```

## Examples
```
/frappe:tour 'Equipment Loan'
```

## Description
Invokes `frappe-interactive-guided-tour-author` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
