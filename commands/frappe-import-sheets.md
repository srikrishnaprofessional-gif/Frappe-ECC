# /frappe:import-sheets

Convert Excel workbooks, CSV files, or Google Sheets into relational Frappe DocTypes and import cleansed records.

## Usage
```
/frappe:import-sheets [file_path]
```

## Examples
```
/frappe:import-sheets path/to/legacy_equipment_inventory.xlsx
```

## Description
Invokes `frappe-excel-csv-app-converter` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
