# /frappe:white-label

1-click corporate visual identity customizer: apply branded palettes, Google Fonts, and custom Desk CSS.

## Usage
```
/frappe:white-label [primary_color_hex] [company_name]
```

## Examples
```
/frappe:white-label '#0d9488' 'Acme Global Logistics'
```

## Description
Invokes `frappe-white-label-branding-themer` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
