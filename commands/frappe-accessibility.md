# /frappe:accessibility

Audit and enforce WCAG 2.1 AA accessibility standards, screen reader compatibility, and keyboard navigation.

## Usage
```
/frappe:accessibility [route_or_doctype]
```

## Examples
```
/frappe:accessibility desk/equipment-loan
```

## Description
Invokes `frappe-accessibility-wcag-compliance` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
