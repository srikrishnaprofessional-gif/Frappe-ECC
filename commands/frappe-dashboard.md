# /frappe:dashboard

Build executive BI dashboards, real-time KPI scorecards, and automated board deck PDF exports.

## Usage
```
/frappe:dashboard [workspace_name]
```

## Examples
```
/frappe:dashboard 'Loan Operations Executive'
```

## Description
Invokes `frappe-bi-dashboard-synthesizer` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
