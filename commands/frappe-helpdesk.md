# /frappe:helpdesk

Deploy a 24/7 AI-powered customer support copilot trained on the application's Working SOP and docs.

## Usage
```
/frappe:helpdesk deploy
```

## Examples
```
/frappe:helpdesk deploy --channel in-app
```

## Description
Invokes `frappe-helpdesk-customer-support-copilot` to execute the specialized workflow within the Frappe Framework and ERPNext runtime environment.
